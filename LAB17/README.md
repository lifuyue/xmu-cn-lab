# 第17课 文件传输协议

本目录用于第17课程序设计题。习题集中该课程序设计题标注为“暂缺”，因此这里保留一个与 FTP 协议主题对应的 C++17 演示程序，用于说明 FTP 控制连接、主动模式、被动模式和响应码解析。

## C++ 复现实验

`15/main.cpp` 不连接外部 FTP 服务器，而是复现 FTP 控制通道中的典型文本命令与响应处理：

- 解析 FTP 三位响应码；
- 判断响应类别，例如成功、等待更多信息、连接准备就绪；
- 将主动模式 `PORT h1,h2,h3,h4,p1,p2` 转换为数据连接地址；
- 将被动模式 `227 Entering Passive Mode (...)` 转换为服务器数据连接地址；
- 输出主动模式与被动模式中 Socket 客户端/服务器端角色的差异。

```bash
make -C LAB17
./LAB17/15/ftp_mode_demo
```
