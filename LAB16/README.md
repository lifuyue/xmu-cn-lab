# 第16课 电子邮件

本目录用于第16课程序设计题。题目要求搭建一个带注册和邮箱验证功能的系统：用户输入昵称、口令和邮箱后提交，邮箱收到带验证码链接的邮件；一小时内访问链接则激活会员，超时未激活则释放昵称。

## C++ 复现实验

`17/main.cpp` 使用 C++17 和 POSIX socket 实现一个本地 HTTP 服务，包含：

- `GET /`：注册页面；
- `POST /register`：提交昵称、口令和邮箱，生成验证码；
- `GET /verify?user=hw&code=ABCDEF`：校验验证码并激活用户；
- `GET /users`：查看当前用户状态；
- `outbox/*.eml`：模拟发送到邮箱的激活邮件。

验证码由用户名、邮箱和固定盐值做 FNV-1a 哈希得到。示例程序不保存明文口令，只保存口令哈希；为避免提交真实邮箱凭据，邮件发送环节以生成 EML 文件的方式演示，实际部署时可将 `write_mail` 替换为 SMTP 投递。

```bash
make -C LAB16
cd LAB16
./17/email_verify_demo 8080
```

浏览器打开：

```text
http://127.0.0.1:8080/
```

注册后查看 `LAB16/outbox/` 下生成的邮件文件，访问邮件中的激活链接即可完成验证。
